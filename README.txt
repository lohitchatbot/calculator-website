Easy Calculator Project

Location: D:\website\calculator-website

What is here:
- index.html: main calculator page
- css/style.css: styling
- js/calculator.js: calculator logic
- js/history.js: calculation history
- js/theme.js: dark/light mode
- blog/: simple article pages

How to preview locally:
1. Open the folder in VS Code
2. Start a simple server from this folder
3. Open http://127.0.0.1:8000/

Example command:
python -m http.server 8000
